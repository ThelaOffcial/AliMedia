# අලිMedia (AliMedia) • Sri Lankan Domesticated Elephants & Tuskers Cultural Registry

> **Verified Cultural Discovery Platform, Heritage Archives, and Sacred Pageantry Dossiers for Sri Lanka's Revered Domesticated Elephants and Majestic Ceremonial Tuskers (හීලෑ අලි සහ ඇත්තු).**

---

## 🌟 Overview

**අලිMedia** is an interactive, bilingual digital archive and registry celebrating the living heritage and history of Sri Lanka's domesticated elephants and ceremonial tuskers. It documents historical biographies, anatomical characteristics, tusk curvature, temple custodianship, mahout lineages, and sacred *Perahera* relic-bearing duties.

---

## ✨ Features

### 🐘 1. National Elephant Dossiers & Registry
- **Living & Memorial Legends**: Comprehensive archives for **Nadungamuwa Raja**, **Maligawa Raja**, **Indiraja**, **Kataragama Vasana**, **Kandula**, **Sinha Raja**, **Abhaya**, **Millangoda Raja**, **Sama**, **Singithi**, and more.
- **Bilingual Interface**: Seamless instant toggle between **Sinhala (සිංහල)** and **English**.
- **Verified Custody Records**: Microchip, DNA registration indicators, custodian temples, and mahout lineages.
- **Tusk Anatomy & Specs**: Detailed measurements and traditional classifications (*Bhumisparsha*, symmetrical ivory).
- **Favorites & Bookmarks**: Save profiles locally to access anytime.

### 👑 2. Sacred Perahera Pageants Directory
- Roster and schedules for Sri Lanka's historic religious festivals:
  - **Kandy Esala Maha Perahera** (*මහනුවර ඇසළ මහා පෙරහැර*)
  - **Kelaniya Duruthu Maha Perahera** (*කැලණිය දුරුතු පෙරහැර*)
  - **Colombo Gangaramaya Navam Perahera** (*ගංගාරාම නවම් මහා පෙරහැර*)
  - **Ruhunu Maha Kataragama Esala Perahera** (*කතරගම ඇසළ පෙරහැර*)
  - **Bellanwila Esala Perahera** (*බෙල්ලන්විල ඇසළ පෙරහැර*)
- Lineup of participating tuskers with links to dossiers.
- Chief Relic Casket Bearer (*කරඬුව වඩමවන ඇතා*) highlighting.

### ⚖️ 3. Side-by-Side Tusker Comparison Matrix
- Compare up to 3 elephants simultaneously across:
  - Tusk length and alignment
  - Height & age
  - Temple custodian & location
  - Perahera relic bearing experience
  - Living / Memorial status

### 📜 4. Ancient Gaja Shastra & Legal Welfare Gazette
- **The 10 Auspicious Castes (*දස හස්ති කුල*)**: *Chaddanta (සද්දන්ත)*, *Uposatha (උපෝසථ)*, *Hema (හේම)*, *Mangala*, *Gandha*, etc.
- **Sacred Regalia Anatomy**: *Nalalpatiya*, *Kasthuru*, *Pavada* traditions.
- **Wildlife Conservation Gazette No. 2241/41 (2021)**: Domesticated elephant welfare standards, daily bathing requirements, and mahout certification rules.

### 📸 5. Community Gallery & Procession Stories
- High-resolution photo feed with photographer attribution.
- Story Reels viewer for featured festival sightings.
- Interactive likes and community discussion/comments.
- "Submit Sighting Photo" modal for cultural photographers.

### 🥁 6. Built-in Web Audio Ceremonial Hewisi Synthesizer
- Interactive traditional *Geta Beraya* and *Hewisi* rhythm ambience with one-click player.
- Authentic synthesised elephant trumpet call effect.

### 🛡️ 7. Full Administrative Portal (`#admin`)
- Accessible via navigation or direct URL hash: `/#admin`
- PIN Authentication (Default Master PIN: `1234` or 1-click bypass).
- **CRUD Operations**: Add new elephants, edit existing dossiers, toggle verified status, manage Perahera pageants, moderate photos.
- **Backup & Restore**:
  - One-click **JSON Database Export**
  - **CSV Spreadsheet Export**
  - **JSON Data Restore**

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/alimedia-elephant-registry.git
cd alimedia-elephant-registry

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser.

---

## 📦 Building for Production

```bash
# Build the optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

The output files will be in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
